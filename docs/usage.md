# Timeflow Calendar 使用指南

1.0.0 提供连续时间轴、事项管理和本地保存。

## 安装与更新

1. 在 [GitHub Releases](https://github.com/crazysong11/Timeflow-Calendar/releases/tag/v1.0.0) 下载 `Timeflow-Calendar_1.0.0_x64-setup.exe`，适用于 Windows 10/11 的 x64 电脑。
2. 运行安装包，选择安装语言并按向导完成安装。默认位置为 `%LOCALAPPDATA%\Timeflow Calendar`，开始菜单提供启动入口。
3. 从开始菜单打开 Timeflow Calendar。安装向导支持简体中文和英文，应用界面目前使用简体中文。

应用使用 Microsoft WebView2；安装向导会检测已有运行时，并在需要时联网安装。本版安装包尚未进行代码签名。发布页同时提供 `SHA256SUMS.txt`，可使用 PowerShell 的 `Get-FileHash -Algorithm SHA256` 比对安装包。

更新时先通过托盘退出应用，再运行新版安装包。日程与窗口偏好保存在独立的用户数据目录。卸载入口位于 Windows 设置的“已安装的应用”；保留“删除应用数据”选项为未勾选状态，即可保留日程和布局。

托盘“关于 Timeflow Calendar”显示版本、许可证与对应源码地址。安装目录中的 `LICENSE` 和 `THIRD_PARTY_NOTICES.txt` 提供完整许可文本。源码运行方式见 [Windows 开发指南](development.md)。

## 打开应用

Windows 应用采用单实例运行。再次运行 exe 会复用现有日历；普通窗口显示到前台，最小化时自动恢复。桌面模式保留固定状态、位置和大小，按 Win+D 回到桌面即可查看。完全退出后可正常重新打开。

## 浏览时间

- 打开时默认使用自动视野，1.0.0 中每小时约占 140 像素；开发分支中普通窗口为 105–140、桌面面板为 87.5–122.5 个 CSS 像素，随界面尺寸比例调整；窗口越宽，可见时间越多。当前时刻位于视图左侧约四分之一处。
- 拖动空白处左右浏览；触控板横向滑动或鼠标滚轮也可以移动时间轴。
- 重叠事项较多、时间轴出现纵向滚动条时，普通滚轮用于上下查看事项，Shift + 滚轮或触控板横向滑动用于浏览时间。
- 左右箭头按钮每次移动半屏；聚焦时间轴后，键盘左右方向键每次移动一小时。
- 日期输入框配合“前往”，将选定日期的 00:00 对齐到时间轴左侧。
- “视野”提供自动和固定 4、8、12、24 小时范围。自动模式旁会显示当前覆盖时长；切换模式或调整窗口宽度时，保持视图四分之一位置对应的时刻稳定。固定模式始终显示选定时长。
- “回到现在”定位当前时刻。浏览与编辑期间，视图位置由你控制；当前时刻标线每 15 秒更新。

开发分支已加入窗口尺寸缩放：字号、按钮、图标、间距和事项卡片随可用窗口宽高一起调整，普通窗口尺寸比例为大窗口布局的 75%–100%，桌面面板为 62.5%–87.5%。达到下限后继续缩小窗口，控件保持最小尺寸，通过换行与滚动容纳内容。正文至少 12 个 CSS 像素，辅助文字至少 11 个 CSS 像素，主要按钮高度至少 32 个 CSS 像素。

桌面模式采用更紧凑的工具栏、卡片和留白，缩小到宽度 640 或高度 480 CSS 像素时达到尺寸下限。编辑表单也随窗口缩放，较窄时起止时间上下排列，较矮时可以纵向滚动。窗口变化保持当前浏览位置，固定视野继续保持选定时长。此项改进将在后续安装包中提供。

小时刻度保持等距，日期头部标明每段时间的日期归属。较宽的时间范围会减少小时文字标签，保留每小时刻度。

## 安排事项

点击“新建事项”或双击时间轴空白处，填写标题和起止时间后保存。双击创建的初始时刻按最近的 5 分钟定位，表单支持精确到分钟；新事项默认持续一小时。

例如，跨午夜阅读可以填写开始时间 `2026-11-15 23:30`、结束时间 `2026-11-16 00:30`。它作为一个事项保存，并连续跨过午夜显示。

事项支持备注和四种颜色。重叠事项自动分行；较短的事项也可以从时间轴下方的列表打开。超出当前视野的事项在边缘截取显示，起止时间保持完整。

点击卡片或列表编辑事项。“30 分钟”和“1 小时”按钮根据开始时间设置结束时间。点击“删除事项”后，确认删除或保留事项。保存失败时窗口保留填写内容，可继续修改和重试。

## 拖动、完成和撤销（开发分支）

- 拖动事项主体改变开始时间，同时保留原时长；拖动左右边缘分别调整开始和结束时间。边缘在实际起止点可见且卡片宽度至少 24 CSS 像素时提供，较短或截断的事项可用编辑表单调整。
- 默认以 5 分钟为步长，按住 Shift 以 1 分钟微调；最短时长为 1 分钟。拖动时显示起止时间，松开后保存；Esc 或拖动期间按 Ctrl+Z 取消当前拖动，窗口变化也会取消当前拖动。
- 右键时间轴卡片或下方列表，选择“标记为完成”；已完成事项显示勾号与标题划线，仍保留在原时间位置。再次右键可“恢复未完成”。左键打开编辑窗口，也可勾选“已完成”后保存。
- 工具栏中的回弯箭头按钮撤销最近一次事项操作，支持新增、编辑、删除、拖动和完成状态修改；也可按 Ctrl+Z。最多保留本次运行最近 50 步，重新打开应用后开始新的撤销记录。表单输入框内的 Ctrl+Z 继续撤销文字输入。
- 写入成功后操作进入撤销记录；保存失败保留原日程，撤销失败时可以重试。

## 外观设置（开发分支）

点击右上角齿轮打开外观设置，修改后立即应用并保存在本机：

- 主题：浅色、深色或跟随 Windows 系统主题。
- 界面大小：90%、100%、110%、120%，叠加在窗口自动缩放上，正文保留最低 12 CSS 像素。
- 桌面事项列表：选择在固定面板中显示或隐藏时间轴下方的列表；普通窗口继续显示列表。
- “恢复默认外观”恢复跟随系统、100% 大小并显示桌面列表。

外观设置与日程分别保存。以上开发分支功能随下一版安装包提供。

## 贴到桌面

Windows 应用右上角点击“贴到桌面”，日历切换为紧凑的桌面面板。其他应用可以覆盖它；按 Win+D 回到桌面后继续查看和操作。

点击“调整布局”，拖动顶部调整条移动位置，拖动右下角改变大小。聚焦调整控件后，方向键每次微调 10 个逻辑像素，按住 Shift 每次调整 50 个逻辑像素。“完成调整”锁定布局；时间轴空白区域继续用于浏览时间。

普通窗口与桌面面板分别保存位置和尺寸：“贴到桌面”恢复上次的桌面布局，“恢复窗口”恢复上次的普通窗口布局。首次贴到桌面时，以当前普通窗口的位置和尺寸作为初始桌面布局。普通窗口的最大化状态也会保存。

普通窗口移动或缩放时自动更新记录，桌面模式在每次结束调整时保存。重新启动会恢复上次使用的模式，两套布局继续保留。点击系统托盘中的 Timeflow 图标，也可恢复窗口、贴到桌面或退出应用。

模式与布局保存在 `%APPDATA%\app.timeflow.calendar\desktop.json`。桌面集成实现与验证范围见[桌面模式设计](desktop-mode.md)。

## 数据保存与备份

Windows 应用在每次成功保存后写入 SQLite，重新启动后恢复。数据库位于当前 Windows 用户的应用配置目录：

```text
%APPDATA%\app.timeflow.calendar\timeflow.db
```

备份时先关闭所有 Timeflow Calendar 窗口，再复制该目录中的 `timeflow.db`；如目录中存在同名的 `-wal`、`-shm` 文件，一并保留。恢复时同样先关闭应用，再用完整备份替换对应数据库文件。

浏览器预览使用当前站点的 localStorage，键为 `timeflow.preview.events.v1`，与桌面数据库各自保存。更换浏览器、预览地址或清除站点数据会影响浏览器预览中的日程。
