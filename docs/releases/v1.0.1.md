# Timeflow Calendar 1.0.1

本次更新改进小窗口和桌面面板的显示，并加入更直接的事项操作。

## 相较 1.0.0 的更新

- **窗口适配**：字号、图标、按钮和事项卡片随窗口宽高缩放，达到最小尺寸后保持稳定；桌面固定模式采用独立的紧凑布局。
- **拖动调整事项**：拖动卡片移动时间，拖动左右边缘调整起止时间；默认以 5 分钟为步长，Shift 按分钟微调，Esc 取消当前拖动。
- **撤销操作**：新增回弯箭头按钮与 Ctrl+Z，支持撤销新增、编辑、删除、拖动和完成状态修改，保留本次运行最近 50 步。
- **完成标记**：右键卡片或列表即可标记完成或恢复未完成；编辑窗口也可设置完成状态，完成后显示勾号与标题划线。
- **外观设置**：新增浅色、深色、跟随系统主题，90%–120% 界面大小，以及桌面事项列表开关。偏好保存在本机。

## 升级

从托盘退出应用，运行 `Timeflow-Calendar_1.0.1_x64-setup.exe` 覆盖安装。日程与窗口布局保留，旧事项默认未完成。附件 `SHA256SUMS.txt` 提供安装包校验值；本版安装包尚未进行代码签名。

## English — Changes since 1.0.0

- **Adaptive sizing:** text, icons, controls, and event cards scale with the window and keep minimum sizes. Pinned desktop panels use a separate compact layout.
- **Drag and resize events:** move cards to reschedule, or drag either edge to change start/end times. Adjust in five-minute steps, hold Shift for one-minute steps, and press Esc to cancel.
- **Undo:** a curved-arrow button and Ctrl+Z undo event creation, edits, deletion, dragging, and completion changes. The latest 50 actions are available during the current session.
- **Completion:** mark events complete or incomplete from the context menu or editor. Completed events display a checkmark and a struck-through title.
- **Appearance settings:** light, dark, and system themes; 90%–120% interface sizing; and an option to hide the event list in desktop mode. Preferences are saved locally.

Exit through the tray, then run `Timeflow-Calendar_1.0.1_x64-setup.exe` to update. Existing events and window layouts are preserved; older events start as incomplete. The installer is unsigned. Checksums are included in `SHA256SUMS.txt`.
