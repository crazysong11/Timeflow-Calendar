# 桌面模式

## 目标与状态

让 Timeflow Calendar 成为桌面上的日程面板：回到桌面即可查看时间轴，在面板上直接安排事项。已实现桌面固定、直接移动和缩放、布局保存、普通窗口恢复及托盘入口。验证状态集中记录在文末。

## 操作设计

1. 普通窗口右上角提供“贴到桌面”。进入后隐藏系统标题栏，采用紧凑布局，继续支持时间浏览、事项编辑和本地保存。
2. 桌面模式提供“调整布局”。开启后，拖动顶部调整条移动面板，拖动右下角调整大小；方向键每次调整 10 个逻辑像素，按住 Shift 时每次调整 50 个逻辑像素。
3. “完成调整”收起布局控件，固定面板位置。时间轴空白区域继续用于浏览时间。
4. “恢复窗口”切回普通窗口。托盘菜单提供普通窗口、贴到桌面和退出入口。
5. 重复打开应用时复用现有实例，并保留桌面固定状态与布局。
6. 普通窗口与桌面面板分别保存位置和尺寸，往返切换时恢复对应布局。首次进入桌面模式时沿用当前普通窗口的布局。
7. 下次启动恢复上次的模式并保留两套布局。普通窗口同时记住最大化状态，最小化时保留还原尺寸。显示器布局变化时，将保存的位置约束在最近显示器的工作区内。

## 实现设计

- `src-tauri/src/desktop.rs`：Windows 桌面宿主查找、窗口挂接与恢复、位置尺寸调整、托盘和配置保存。
- `src/components/DesktopMode.tsx`：模式状态、操作入口和反馈。
- `src/components/DesktopLayout.tsx`：移动与缩放手柄、指针捕获和键盘微调。
- 使用 Windows `SetParent` 将应用窗口挂接到含 `SHELLDLL_DefView` 的 `Progman` 或 `WorkerW` 桌面宿主，配套切换窗口样式。恢复时还原原有样式和普通窗口关系。
- 通过窗口缩放因子把交互位移换算为物理像素；调整大小时保留最小逻辑尺寸 640 × 480。可见时间范围继续由自动视野计算。1.0.1 为桌面面板提供 62.5%–87.5% 的独立尺寸范围，缩至宽度 640 或高度 480 CSS 像素时停止缩小；正文至少 12 像素，主要按钮至少 32 像素，卡片至少 54 像素高。工具栏和上下间距同步收紧。
- 配置文件为 `%APPDATA%\app.timeflow.calendar\desktop.json`，与日程数据库分别保存。写入采用临时文件再替换，读取失败时使用普通窗口。
- 配置分别记录 `normal_bounds`、`desktop_bounds` 和 `normal_maximized`，`enabled` 表示当前模式。旧配置的 `bounds` 自动作为桌面布局读取。
- 普通窗口通过 Tauri 的移动与缩放事件记录屏幕坐标和外框尺寸；最大化、最小化保留还原尺寸。桌面模式在每次结束移动或缩放时保存桌面布局；模式切换同时保存两套记录。
- 原生窗口快照保留普通窗口样式、位置、尺寸与最大化状态，桌面调整只更新桌面布局。事件回调使用非阻塞锁，模式切换产生的同步窗口事件由切换流程统一记录。

Windows 桌面宿主层级需要在目标系统上验证。重点检查显示桌面、桌面图标、输入焦点、系统缩放和资源管理器生命周期。

## 验收项目

- 普通窗口与桌面模式往返切换，系统标题栏、任务栏与托盘入口表现一致。
- 打开其他应用后，日历留在桌面层；使用 Win+D 后仍可查看日历。
- 在桌面模式中直接移动和缩放，完成后保持位置，时间轴拖动继续用于浏览。
- 缩小至最小尺寸、大窗口与高 DPI 环境下，位置和尺寸换算正确。
- 桌面模式中打开与关闭事项编辑表单，保存与 SQLite 数据保持一致。
- 退出并重新启动，恢复模式、位置和尺寸。
- 将普通窗口与桌面面板设为不同的位置和尺寸，多次往返及重启后各自恢复；普通窗口最大化后切换也能恢复最大化状态。
- 从托盘恢复普通窗口并退出应用。
