# Timeflow Calendar 使用指南

第一版提供连续时间轴、事项管理和本地保存。启动方式见 [Windows 开发指南](development.md)。

## 浏览时间

- 打开时显示当前时刻附近的 8 小时，当前时刻位于视图左侧约四分之一处。
- 拖动空白处左右浏览；触控板横向滑动或鼠标滚轮也可以移动时间轴。
- 重叠事项较多、时间轴出现纵向滚动条时，普通滚轮用于上下查看事项，Shift + 滚轮或触控板横向滑动用于浏览时间。
- 左右箭头按钮每次移动半屏；聚焦时间轴后，键盘左右方向键每次移动一小时。
- 日期输入框配合“前往”，定位到选定日期的 08:00。
- “视野”提供 4、8、12、24 小时范围，切换时保持视图四分之一位置对应的时刻稳定。
- “回到现在”定位当前时刻。浏览与编辑期间，视图位置由你控制；当前时刻标线每 15 秒更新。

小时刻度保持等距，日期头部标明每段时间的日期归属。较宽的时间范围会减少小时文字标签，保留每小时刻度。

## 安排事项

点击“新建事项”或双击时间轴空白处，填写标题和起止时间后保存。双击创建的初始时刻按最近的 5 分钟定位，表单支持精确到分钟；新事项默认持续一小时。

例如，跨午夜阅读可以填写开始时间 `2026-11-15 23:30`、结束时间 `2026-11-16 00:30`。它作为一个事项保存，并连续跨过午夜显示。

事项支持备注和四种颜色。重叠事项自动分行；较短的事项也可以从时间轴下方的列表打开。超出当前视野的事项在边缘截取显示，起止时间保持完整。

点击卡片或列表编辑事项。“30 分钟”和“1 小时”按钮根据开始时间设置结束时间。点击“删除事项”后，确认删除或保留事项。保存失败时窗口保留填写内容，可继续修改和重试。

## 数据保存与备份

Windows 应用在每次成功保存后写入 SQLite，重新启动后恢复。数据库位于当前 Windows 用户的应用配置目录：

```text
%APPDATA%\app.timeflow.calendar\timeflow.db
```

备份时先关闭所有 Timeflow Calendar 窗口，再复制该目录中的 `timeflow.db`；如目录中存在同名的 `-wal`、`-shm` 文件，一并保留。恢复时同样先关闭应用，再用完整备份替换对应数据库文件。

浏览器预览使用当前站点的 localStorage，键为 `timeflow.preview.events.v1`，与桌面数据库各自保存。更换浏览器、预览地址或清除站点数据会影响浏览器预览中的日程。

## 当前范围

第一版优先覆盖连续浏览与日程安排。事项拖动调整、提醒、重复规则和云同步留待后续讨论；当前通过表单修改事项的起止时间。
