# Timeflow Calendar 基本需求

Timeflow Calendar 以连续时间轴支持日程安排，首先面向 Windows。本文记录基本要求、第一版实现和验收场景，为后续迭代提供依据。

## 产品目标

将时间呈现为均匀、连续的流，支持用户从任意时刻安排事项。日期和小时帮助定位，午夜前后的时间在同一视图中自然衔接。

## 已明确的基本要求

| 编号 | 要求 | 预期表现 |
| --- | --- | --- |
| R1 | 面向 Windows | 首先开发 Windows 上使用的软件。 |
| R2 | 连续时间轴 | 按时间顺序连续展示，跨越日期时保持连接。 |
| R3 | 小时刻度 | 按小时划分时间轴，同等时长在同一缩放比例下占据相同宽度。 |
| R4 | 左右浏览 | 支持通过左右拖动或滑动查看不同时间。 |
| R5 | 安排事项 | 可以在某一小时内安排事项，也可以让事项跨越多个小时。 |
| R6 | 日期头部 | 在时间轴上方显示日期归属，能够判断某小时属于哪一天。 |
| R7 | 逐步完善 | 从基本要求开始实现，根据讨论和实际使用逐步扩展。 |
| R8 | 桌面固定 | 提供贴到 Windows 桌面的模式，其他应用正常覆盖日历；返回桌面后可继续查看和编辑。 |
| R9 | 桌面布局调整 | 在桌面模式中直接移动和调整大小，完成后锁定布局，并保存模式、位置和尺寸。 |
| R10 | 独立布局记忆 | 普通窗口与桌面面板分别保存位置和大小，切换模式时恢复对应布局，重启后保留两套记录；普通窗口同时保存最大化状态。 |
| R11 | 随窗口调整界面尺寸 | 字号、图标、控件、间距与事项卡片随窗口宽高调整；桌面固定面板采用独立紧凑布局，接近 640 × 480 逻辑尺寸时达到缩小下限；使用换行和滚动展示更多内容。 |

23:00 到次日 00:00 与 22:00 到 23:00 的显示间距相同，跨越午夜时保持连续布局。

## 开发分支新增要求与实现

| 编号 | 要求 | 当前实现 |
| --- | --- | --- |
| R12 | 直接调整事项 | 拖动主体保留时长，两端分别调整起止；5 分钟步长、Shift 按分钟微调、Esc 取消。 |
| R13 | 撤销事项操作 | 回弯箭头按钮与 Ctrl+Z，覆盖新增、编辑、删除、时间调整及完成状态，保留本次运行最近 50 步。 |
| R14 | 完成标记 | 时间轴和列表右键菜单提供完成及恢复入口；编辑表单提供完成复选框，状态持久保存。 |
| R15 | 外观设置 | 浅色、深色、跟随系统；界面大小 90%–120%；桌面事项列表开关，保存偏好并可恢复默认。 |

这些新增功能随下一版安装包交付；验证范围见开发指南。

## 第一版已实现功能

第一版已实现以下基本使用流程，操作说明见[使用指南](usage.md)。

- 当前时刻标线，以及“回到现在”入口。
- 事项新增、编辑、删除；最初只要求标题、开始时间和结束时间。
- 支持非整点起止时间，例如 10:35 至 11:05。
- 跨午夜事项作为一个事项保存，并在时间轴上连续显示。
- 本地保存事项，关闭并重新打开程序后恢复数据。

同时提供自动视野与固定 4、8、12、24 小时视野切换、日期跳转、备注与颜色。提醒、账号、云同步、多人协作、重复规则和统计功能列入后续评估。

## 第一版交互约定

| 问题 | 当前实现 |
| --- | --- |
| 打开时显示哪里 | 展示当前时刻附近，当前时刻位于视图左侧四分之一处。 |
| 一屏显示多少小时 | 默认自动适配窗口宽度，每小时约 140 像素；可选固定 4、8、12、24 小时。 |
| 重复打开应用 | 复用现有实例；普通窗口恢复并聚焦，桌面模式保持原布局。 |
| 日期跳转起点 | “前往”将选定日期的 00:00 对齐到时间轴左侧。 |
| 日期头部如何跨天 | 日期带覆盖各自对应的时间范围；午夜使用较轻的分界。 |
| 如何创建和编辑事项 | 点击“新建事项”或双击空白处创建；点击卡片或列表打开表单编辑。 |
| 浏览与编辑如何配合 | 空白区域拖动用于浏览，事项区域提供编辑操作。 |
| 两个事项重叠怎么办 | 允许重叠并自动分行；首尾相接的事项可以复用同一行。 |
| 窗口适配 | 正文与控件采用清晰字号；布局按宽高调整，浏览锚点在窗口变化时保持稳定。 |
| 时间是否吸附 | 双击创建按最近 5 分钟定位；表单精确到分钟，小时作为视觉刻度。 |
| 用户浏览时是否跟随现在 | 浏览或编辑期间保持视图位置，由“回到现在”主动返回。 |

这些交互约定作为日常试用的起点，后续根据操作体验调整。

## 核心验收场景

以下场景用于验证第一版功能。

1. 将时间轴拖到午夜附近，23:00、00:00、01:00 在同一视图中等距排列，前后日期标注清楚。
2. 左右拖动时间轴，可以连续查看过去与未来，日期头部与小时刻度对应正确。
3. 创建一个小时内的事项和一个跨小时事项，两者的位置与宽度符合起止时间。
4. 查看跨月或跨年的相邻小时，时间保持连续，日期归属正确。
5. 创建 23:30 至次日 00:30 的事项，它保留为一个事项，连续跨越午夜显示。
6. 创建、修改、删除事项后关闭并重启程序，保存的状态正确恢复。

## 体验验证

分别在 10:37 和 23:40 附近使用原型，观察能否容易地定位此刻、理解接下来的时间并开始安排。记录具体困难，例如日期难以识别、拖动误触或时间选择费力，再据此调整。

## 技术方案

桌面模式已实现固定、直接移动和缩放，交互设计和验收记录见[桌面模式设计](desktop-mode.md)。

采用 Tauri 2 + React + TypeScript + CSS，使用 Vite 和 npm 构建，SQLite 与 Tauri SQL 插件负责本地保存。详见[技术方案](technical-design.md)。
