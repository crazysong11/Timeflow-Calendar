# Timeflow Calendar 1.0.0

首个 Windows 正式版本。让日程沿连续时间轴展开，从此刻开始安排时间。

## 下载与安装

- 系统：Windows 10/11，x64。
- 安装包：`Timeflow-Calendar_1.0.0_x64-setup.exe`。
- 校验文件：`SHA256SUMS.txt`。
- 运行安装向导后，从开始菜单启动 Timeflow Calendar。需要 WebView2 时，安装程序会联网安装运行时。
- 安装向导支持简体中文与英文，应用界面使用简体中文。本版安装包尚未进行代码签名。

## 本版功能

- 连续的小时刻度与日期头部，跨午夜自然衔接。
- 拖动、滚轮和键盘浏览时间，回到现在或跳转到指定日期的 00:00。
- 自动适配窗口的视野，以及固定 4、8、12、24 小时视野。
- 新建、编辑和删除事项，分钟级时间、跨天安排、备注与颜色，重叠事项自动分行。
- SQLite 本地保存。
- 固定到 Windows 桌面，直接移动和调整大小，托盘恢复普通窗口或退出。
- 普通窗口和桌面面板各自记住位置与大小，普通窗口同时记住最大化状态。
- 单实例运行，重复启动时复用已有日历。

日程及窗口布局位于 `%APPDATA%\app.timeflow.calendar`。更新前通过托盘退出应用，再运行安装包。使用说明与备份步骤见 [使用指南](https://github.com/crazysong11/Timeflow-Calendar/blob/v1.0.0/docs/usage.md)。

## English

The first Windows release of Timeflow Calendar: a continuous timeline calendar for planning from this moment.

Download `Timeflow-Calendar_1.0.0_x64-setup.exe` for Windows 10/11 x64 and follow the setup wizard. Launch the app from the Start menu. Setup supports English and Simplified Chinese; the app interface is in Simplified Chinese. WebView2 is installed over the internet when needed. This release is unsigned; `SHA256SUMS.txt` provides a checksum for the installer.

Features include continuous hourly navigation across midnight, minute-level event editing, overlapping event rows, SQLite persistence, responsive automatic and fixed time spans, an adjustable Windows desktop mode, separate saved layouts for regular and pinned windows, and single-instance startup.

Calendar data and layouts are stored in `%APPDATA%\app.timeflow.calendar`. Exit through the tray before updating.
